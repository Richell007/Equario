# Equario
Repositório com o código-fonte de um sistema de gerenciamento para aquaristas. O software foca no armazenamento de parâmetros da água, catálogo de habitantes do aquário e registro histórico de manutenções periódicas.
Para ver o diagrama versão 3.0 basta: 
No Windows: baixar a extensão PlantUML do jebbs no vscode, e visualizar o preview com alt+d no arquivo puml
